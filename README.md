# Wordly

A simple word-search application built with HTML, CSS and JavaScript. The application was designed to allow users to search for words and retrieve information from an external dictionary API.

## Live Demo

[View the live application](https://wordly-ruby.vercel.app/)

> **Current status:** The application is deployed, but the external dictionary API request is currently failing, so word searches may not return results.

## Features

* Search for words
* Fetch word information from an external API
* Display search results dynamically
* Interactive user interface

## Technologies Used

* HTML
* CSS
* JavaScript
* External API

## Running Locally

Clone the repository:

```bash
git clone https://github.com/penzimbuthia-sudo/wordly.git
```

Navigate into the project:

```bash
cd wordly
```

Open the application in your browser or run it using a local development server.
